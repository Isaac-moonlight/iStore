## 🚀 Comment remplacer une image sur GitHub ?

1. Ouvrez ce dossier : `public/products/`
2. Repérez le nom du produit (ex: `sony-wh-1000xm5.png`, `iphone-18-pro-max.png`, `samsung-s24-ultra.png`)
3. Cliquez sur le fichier puis utilisez **Add file > Upload files** pour téléverser votre propre photo avec le même nom.
4. Validez en cliquant sur **Commit changes**.
5. Le site affichera immédiatement votre nouvelle photo !
